ONE-TIME SETUP

Connect your learning assistant.

Document search works now. AI explanations and translation need an API key.

  1. In the app folder, copy .env.example to .env.
  2. Set AI_PROVIDER to openai or gemini, then add the matching key after OPENAI_API_KEY= or GEMINI_API_KEY=. Save it locally; never paste it here.
  3. Restart with Start.cmd. Run Enable-AI.cmd only when using OpenAI semantic embeddings.
Questions send your message, recent context, and matching passages to the selected provider. Translation sends the selected answer. API usage is billed separately.
